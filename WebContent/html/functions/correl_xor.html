Función: XOR de Correspondencias/RelacionesVolver

Descripción

Devuelve la correspondencia/relación XOR de otras dos (definidas sobre el mismo dominio/codominio)

Cadena de entrada

correl_xor

Cadena de salida

CORREL.xor

Uso

correl_xor(<correspondencia_relacion>,<correspondencia_relacion>)

Valor devuelto

Diccionario representando la correspondencia/relación resultado de XOR

Ejemplos

correl_xor(correl_nueva(['a','b'],[1,2,3],[[1,1,0],[0,0,0]]),correl_nueva(['a','b'],[1,2,3],[[0,0,0],[1,1,1]]))

Diccionario: { 'dominio': ['a','b'] 'codominio': [1,2,3] 'ady': [[1,1,0],[1,1,1]] }
