Función: Correspondencia/Relación ComplementariaVolver

Descripción

Devuelve la correspondencia/relación complementaria

Cadena de entrada

correl_complementaria

Cadena de salida

CORREL.complementaria

Uso

correl_complementaria(<correspondencia_relacion>)

Valor devuelto

Diccionario representando correspondencia/relación complementaria

Ejemplos

correl_complementaria(correl_nueva(['a','b'],[1,2,3],[[1,1,0],[0,1,0]]))

Diccinario: { 'dominio': ['a','b'] 'codominio': [1,2,3] 'ady': [[0,0,1],[1,0,1]] }
