Función: TablaVolver

Descripción

Crea una matriz con encabezados a partir de una matriz de datos

Cadena de entrada

tabla

Cadena de salida

tabla

Uso

tabla(<encabezados_col>[,<encabezados_fil>],<matriz>)

Parámetros
# Parámetro Descripción Valor por defecto
1 encabezados_col Vector de encabezados de las columnas.
Si se incluyen encabezados de fila, la primera columna deberá ser la esquina izquierda-superior
2 encabezados_fil Vector de encabezados de las filas ∅
2|3 matriz Matriz de datos

Valor devuelto

Matriz:

	| esquina  col1  col2  ... |
	| fila1   |             |  |
	| fila2   | MATRIZ DATA |  |
	|  ...    |             |  |

Ejemplos

tabla(['fil\col','a','b','c'],['X','Y'],[[3,2,1],[1,0,0]])

VectorEvaluado: | 'fil\col' 'a' 'b' 'c' | | 'X' 3 2 1 | | 'Y' 1 0 0 |

tabla(['x','y','z'],[[2,0,1],[-1,0,1],[1,4,9]])

Diccionario: | 'x' 'y' 'z' | | 2 0 1 | | -1 0 1 | | 1 4 9 |
