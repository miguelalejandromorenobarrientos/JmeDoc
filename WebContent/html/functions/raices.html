Función: Raíces enteras de un número complejoVolver

Descripción

Devuelve el conjunto de raíces enteras de un número complejo z1n

Cadena de entrada

raices

Cadena de salida

raices

Uso

raices(<z>,<n>)

Parámetros
# Parámetro Descripción Valor por defecto
1 z Número
2 n exponente entero n en la expresión z1n

Ejemplos

trasp(raices(1,5))
