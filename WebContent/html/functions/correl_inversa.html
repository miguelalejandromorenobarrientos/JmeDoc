Función: Correspondencia/Relación InversaVolver

Descripción

Devuelve la correspondencia/relación inversa (traspuesta, dual, recíproca, conversa)

Cadena de entrada

correl_inversa

Cadena de salida

CORREL.inversa

Uso

correl_inversa(<correspondencia_relacion>)

Valor devuelto

Diccionario representando correspondencia/relación inversa

Ejemplos

correl_inversa(correl_nueva(['a','b'],[1,2,3],[[1,1,0],[0,1,0]]))

Diccinario: { 'dominio': [1,2,3] 'codominio': ['a','b'] 'ady': [[1,0],[1,1],[0,0]] }
