Función: MoldearVolver

Descripción

Convierte una cadena de texto a terminal JME evaluándola. Si no es posible, devuelve la propia cadena

Cadena de entrada

moldear

Cadena de salida

moldear

Uso

moldear(<texto>)

Ejemplos

moldear('3d')

RealGrande: 3

moldear('cos(pi)')

RealDoble: -1

moldear('cos((')

Texto: 'cos(('
